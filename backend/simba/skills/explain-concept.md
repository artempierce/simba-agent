---
name: explain-concept
description: Explain an idea, term or piece of tech the user wants to understand ("what is…", "how does… work", "explain…")
---
Explain one idea so it sticks, without burying the user in detail.

1. Start with one plain definition, one or two sentences. If you need a technical word, explain it in the same line.
2. Give one small, concrete example from everyday life or from the user's own world (use what you know about them).
3. Stop there. Don't add history, edge cases or a list of related ideas unless the user asked for them.
4. End with one short offer to go deeper, e.g. "Want the next layer down?"

If the user already knows the basics (they used the term correctly, or said so), skip step 1 and go straight to what they're missing.
